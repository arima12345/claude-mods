# ja-reply 仕様書：英語の報告を日本語で書き直させる

## 目的

CLAUDE.md で「ユーザーへの返事は必ず日本語」と決めていても、長い作業のあとに Claude が英語で報告してしまうことがあります。直前の文脈がコマンドの出力やコードなどの英語で埋まり、そちらに引っぱられるためです。

この mod は、Claude が返事を終えようとした瞬間に返事の言語を確かめます。ほとんど英語だったら、同じターンの中で日本語の報告に書き直させます。

## 仕組み

`classic.Stop` イベントを使います。このイベントは、メインの Claude が返事を終えて止まろうとしたときに呼ばれます。goal2 や edit-check と同じイベントです。

1. まず、ほかの mod とエンジンの判断を先に聞きます（`next(e)`）。ほかの mod が「まだ止まらず作業を続けて」と止めた場合（`block`）は、何もしません。作業がまだ続くので、最後に止まるときに確かめれば十分だからです。
2. 止まろうとしている返事（`last_assistant_message`）が「ほとんど英語」かどうかを判定します。
3. ほとんど英語なら、設定に応じて次のどちらかを行います。
   - **書き直させる**（初期設定）：止まるのを止めて、日本語で報告し直すよう Claude に伝えます（`block`）。同時に、トーストで知らせます。
   - **知らせるだけ**：トーストで知らせて、そのまま止まらせます。

### 書き直しの依頼文

> 直前の報告がほとんど英語でした。CLAUDE.md の決まりどおり、ユーザーへの報告を日本語で書き直してください。作業の続きはせず、同じ内容の報告を日本語で書くだけにしてください。

### 書き直しは1ターンに1回まで

- 書き直しを頼んだことを `$.state` に記録します。この記録は、ユーザーが新しく依頼を送ったとき（`prompt.submit` のうち、ユーザー自身の入力）に消します。mod が送るプロンプトや、書き直しのために作業が続く場合には消しません。
- 同じターンでもう一度英語になった場合は、書き直しを頼まずに「書き直しも英語でした」とトーストで知らせ、そのまま止まらせます。書き直しの往復が止まらなくなるのを防ぐためです。

### 対象にしないもの

- サブエージェントの返事（`agent_id` あり）。サブエージェントから Claude への報告は英語でかまいません。
- 短い返事。判定に使う文字が 150 文字未満のものは対象外です（「OK」「Done」など）。
- 返事が空のとき（デスクトップアプリのまとめの枠だけで終わる場合など）。

## 「ほとんど英語」の判定

1. 次の部分を取り除きます。英語なのが正常な部分だからです。
   - コードブロック（```` ``` ```` で囲まれた部分）
   - インラインコード（`` ` `` で囲まれた部分）
   - URL
   - ファイルパス（`/` や `\` を含む語）
   - Markdown のリンク先
2. 残りの文字を数えます。
   - 日本語：ひらがな、カタカナ、漢字（半角カタカナを含む）
   - 英字：A〜Z、a〜z
3. 日本語 ÷（日本語＋英字）を「日本語の割合」とします。
4. 日本語と英字を合わせて 150 文字以上あり、日本語の割合が 20% 未満なら「ほとんど英語」とします。

日本語の報告に英語の名前（mod 名、ブランチ名など）が多少混ざっていても、日本語の割合は 20% を大きく上回るので、誤判定はしません。

## 設定（userConfig）

| 項目 | 内容 | 初期値 |
| --- | --- | --- |
| `mode` | `rewrite`（書き直させる）または `notify`（知らせるだけ） | `rewrite` |

## トーストの文面

| 場面 | 文面 |
| --- | --- |
| 書き直しを頼んだ | 返事がほとんど英語だったので、日本語で書き直すよう頼みました |
| 知らせるだけの設定のとき | 返事がほとんど英語でした（日本語の割合 NN%） |
| 書き直しも英語だった | 書き直しも英語でした。必要なら「日本語で」と頼んでください |

## 利用枠への影響

書き直しを頼むと、短いやり取りが1回増えます。英語の返事はたまにしか起きないので、影響は小さいと考えています。気になる場合は `mode` を `notify` にします。

## テスト

`claude plugin test plugins/ja-reply` で、次の場合を確かめます。

- 英語の返事で書き直しを頼み、トーストが出ること
- 日本語の返事、英語の名前が多めの日本語の返事、短い返事、空の返事では何もしないこと
- コードブロックやパスがどれだけ英語でも、地の文が日本語なら何もしないこと
- 書き直しは1ターンに1回までで、新しい依頼で記録が消えること
- サブエージェントの返事と、ほかの mod がすでに止めている場合は何もしないこと
- `notify` の設定では、トーストだけで止まらせること
