# compact-memo

会話の圧縮で、細かい決定事項が抜け落ちるのを防ぐ mod です。

会話が長くなると、Claude Code は古い部分を要約して詰めます（圧縮）。このとき細かい決定事項が抜け落ちて、「さっき決めたことを忘れる」ことがあります。この mod は、圧縮のたびに次の2つを行います。

- **要約への指示**：要約の担当に「ユーザーと合意した決定事項、却下した案とその理由、未解決の問題は、省略せず箇条書きで残すこと」と指示します。`/compact 〇〇` で自分の指示を付けた場合は、その後ろにつなげます。
- **退避メモ**：圧縮の直前の状況のうち、Claude が圧縮後に自分では調べ直せないことだけをメモにまとめ、圧縮後の会話の末尾に足して渡し直します。中身は次のとおりです。
  - どのフォルダの、いつの圧縮か
  - いまのゴール（[goal2](../goal2) を使っている場合）
  - やることリストの残り（[progress-panel](../progress-panel) を入れている場合）
  - いまのブランチ
  - このセッションのコミット（新しい5件）と、最後のテスト・チェックが失敗のままかどうか（progress-panel を入れている場合）

変更中のファイルの一覧や、直前の依頼の引用は入れません。ファイルは Claude が `git status` で調べ直せますし、短い依頼の引用は前後がないと意味をなさないからです。残すことが何もないときは、メモを足しません。

手動の `/compact` でも、自動の圧縮でも動きます。サブエージェントの会話の圧縮と、`/clear` では何もしません。メモを渡し直したときはトーストで知らせます。残すことがなくてメモを作らなかったときも、そのことをトーストで知らせます。どちらの処理も圧縮の中で行うので、API の呼び出しは増えません。

`/compact-memo` は、圧縮を起こすコマンドではなく、見るためのコマンドです（圧縮は `/compact` か自動で起き、そのたびにこの mod が動きます）。このセッションの最後の圧縮と、そのとき渡し直した退避メモ（作らなかったときは、そのこと）を先に出し、そのあとに全セッションの圧縮の記録を出します。ほかのセッションのメモの中身は出しません（そのセッションで打つと見られます）。記録には、手動か自動か、そのときのコンテキスト使用率、どのフォルダのセッションか、メモを作ったかどうかが出ます。この記録から、実際に何%で自動圧縮が始まるかもわかります。

goal2 と progress-panel は入っていなくても動きますが、その場合はブランチ名しか残せないので、メモは足しません（要約への指示だけが効きます）。詳しい仕様は [SPEC.md](SPEC.md) にあります。

## インストール

Claude Code の入力欄で:

```
/plugin install compact-memo --marketplace arima12345/claude-mods
```

マーケットプレイスを追加するか聞かれたら `y`、続けてインストール先（スコープ）を選びます。デスクトップアプリでは、入力欄の横の + から Plugins を開き、Add marketplace に `arima12345/claude-mods` を入れてから Add plugin を選びます。

なお、組織が管理している Claude Code では、圧縮のイベントは組織が許可した mod でしか動きません。
