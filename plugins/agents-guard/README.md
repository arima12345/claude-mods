# agents-guard

AGENTS.md が長くなりすぎたときに知らせる mod です。

AGENTS.md は、毎回の会話で全文が読まれます。長くなるほど、どの会話でもコンテキストを使い、一つひとつの決まりが守られにくくなります。会話の途中で言われたことを足し続けると、気づかないうちに長くなります。この mod は、長さが目安を超えた時点で知らせます。自分で削ったり書き換えたりはしません。

## 知らせること

- **AGENTS.md が目安を超えた**（初期設定は 100行・6,000字）
  > AGENTS.md が目安を超えています（120行・7,400字／目安 100行・6,000字）。削る候補を Claude に出してもらうのがおすすめです。
- **ルートの CLAUDE.md に、`@AGENTS.md` のほかの中身がある**（プロジェクトの指示書は AGENTS.md の1か所に書く決まりのため）

## 知らせるとき

- セッションを始めたとき（超えていれば必ず1回）
- Claude が AGENTS.md（どのフォルダでも）やルートの CLAUDE.md を編集して、さらに長くなったとき。このときは Claude にも「削る候補をユーザーに示して」と一言伝えます。サブエージェントが編集したときは、ターンの終わりにまとめて知らせます
- ターンの終わりに、ルートの AGENTS.md・CLAUDE.md が書き換わっていたとき（シェルのコマンドで書き換えた場合に気づくため）

同じ長さのままなら、二度は知らせません。短くしている途中も知らせません。ただし、ファイルが一度消えてからまた作られたとき（ブランチの切り替えなど）は、目安を超えていれば改めて知らせます。

## 設定

`/plugin configure agents-guard@claude-mods` で変えられます。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| `maxLines` | 100 | 行数の目安 |
| `maxChars` | 6000 | 文字数の目安 |
| `checkClaudeMd` | オン | ルートの CLAUDE.md の中身を見る |

## インストール

```
/plugin install agents-guard --marketplace arima12345/claude-mods
```

詳しい動きは [SPEC.md](SPEC.md) にあります。
