# progress-panel

Claude Code の進捗をひと目で見られるパネルを出す mod です。

- 作業中か待機中（入力待ち）か
- いま何をしているか（「コマンドを実行中」「Webで調べている」など）
- 経過時間とツールを使った回数
- やることリストの進み具合（■■■□□□ 1/3 と、✓ 完了・▶ 取り組み中・・ 未着手）。ターミナルのやることリストにも、デスクトップアプリのタスクリストにも対応しています。全部終わったリストは、次の依頼を打ち込んだ時点で消え、新しい依頼のリストだけが出ます（終わっていない項目が残っていれば、そのまま引き継ぎます）

- 利用枠（5時間枠・週の枠）の使用率と回復時刻、消費ペースが速いときの上限到達の見込み
- コンテキストの使用率と、次の目安（40%・50%・60%）までのターン数の見込み
- 実行中・完了したサブエージェント（種類・作業の説明・経過時間）
- 作業ログ：ファイルの編集、テスト・型チェックなどの結果、コミットを時系列で（直近5件）
- ほかのセッション：同じマシンで progress-panel を入れて動いているほかのセッションの、作業中か待機中か、いまの操作、やることの進み具合、ブランチ

画面下のステータス欄にも「作業中 1/3・コマンドを実行中 ｜ 5時間 62%（18:40 回復）・週 35%・文脈 45%▲」のような一行が出ます。パネルを閉じたら `/progress` で開き直せます。

`/worklog` で、作業ログの全件と、変更したファイル・テストの最後の結果・コミットの一覧を Markdown で出せます。引き継ぎメモの下書きに使えます。シェルコマンドで書き換えたファイルやユーザー自身の編集は記録されないので、正確な変更内容は git で確かめてください。

## ほかのセッションの一覧

worktree を分けて複数のセッションを同時に動かしているとき、ほかのセッションの状況もこのパネルに出ます。

```
ほかのセッション（作業中 1・待機 1）
● claude-mods-session-board（add-session-board）
  作業中 2/5・コマンドを実行中・文脈 45%
  ▶ テストを書く
○ second-brain（main）
  待機中・4分前
  依頼：週次レポートを作って
```

- 各セッションが自分の状況を、この mod 専用の保存場所（`~/.claude/plugins/store/` の下の JSON ファイル）に書き出し、10 秒ごとにほかのセッションの分を読み直します。表示は最大 15 秒ほど遅れます。
- 3 分以上書き出しが途絶えたセッションは「応答なし」と薄く出し、30 分たったら一覧から消します。
- ステータス欄にも ` ｜ 他 作業中2 待機1` のように出ます。
- 出るのは progress-panel 0.5 以降を入れた Claude Code のセッションだけです。Codex やほかのマシンのセッションは出ません。`claude -p` などの人がいないセッションも出しません。
- 依頼の1行目（伏せ字済み・40 文字まで）、取り組み中のやること、フォルダ名、ブランチ名がローカルのファイルに残ります。外へは送りません。スマホなど外からつないだ画面には件数だけを出し、中身は出しません。コンテキストや利用枠は使いません。
- VS Code 拡張のセッションは一覧に出ません。

## 知らせるタイミング

- 利用枠が 80% と 95% を超えたとき、それぞれ一度だけトーストで知らせます。95% のときは OS の通知も送ります（ターミナルのみ。デスクトップアプリには OS 通知の経路がないため、長めのトーストになります）。
- 消費ペースが速く、このままだと回復前に上限に達しそうなときは、一度知らせたうえで、その状態のあいだステータス欄に表示し続けます。
- コンテキストが 40%・50%・60% を超えたときに知らせます。/compact などで下がったら、また知らせます。
- コンテキストが 50% 以上で、作業が区切りに来たとき（やることリストが全部完了した、コミットした、失敗していたテストが通った）に「区切りどきです」と知らせます。一度知らせたら、さらに 10 ポイント増えるまでは知らせません。作業の途中では知らせないので、切りの悪いところで区切らずに済みます。
- 自動圧縮が始まる位置（圧縮の基準値）の 90% を超えたら、区切りかどうかに関係なく「まもなく自動で圧縮されます」と一度知らせます。パネルには、圧縮の基準値まであと何トークンかを出します。自動圧縮を切っているときは知らせません。

圧縮やクリアを自動ですることはありません。いつ区切るかは自分で決めます。圧縮の前に状況をメモに残したい場合は、[compact-memo](../compact-memo) を一緒に入れてください。

利用枠の数値は、そのセッションが最後に受け取った応答の時点のものです。ほかのセッションで使った分は次の応答まで反映されません。API キーで使っているときは利用枠は出ず、コンテキストだけが出ます。詳しい仕様は [SPEC.md](SPEC.md) にあります。

## インストール

Claude Code の入力欄で:

```
/plugin install progress-panel --marketplace arima12345/claude-mods
```

マーケットプレイスを追加するか聞かれたら `y`、続けてインストール先（スコープ）を選びます。

シェルからは:

```
claude plugin install progress-panel --marketplace arima12345/claude-mods
```

デスクトップアプリでは、入力欄の横の + から Plugins を開き、Add marketplace に `arima12345/claude-mods` を入れてから Add plugin を選びます。
