# agents-guard 仕様書：AGENTS.md の太りすぎを知らせる

## 目的

AGENTS.md は、毎回の会話で全文が読まれます。増えるほど、どの会話でもコンテキストを使い、一つひとつの決まりが守られにくくなります。2026-10-25 に見直したところ、youtube要約（229行・12,436字）、Island-survival-game（110行・11,892字）、動画制作（69行・9,235字）が、目安の「100行・6,000字」を大きく超えていました。会話の途中で言われたことを日付つきで足し続け、だれも長さを見ていなかったためです。

全体の指示書（`~/.claude/CLAUDE.md`・`~/.codex/AGENTS.md`）には「増やしすぎない」決まりを入れました。ただ、決まりは、守られなかったときに気づけないと意味がありません。この mod は、AGENTS.md が目安を超えた時点で、ユーザーと Claude に知らせます。書き換えや削除は、自分ではしません。

## 知らせる場面

| 場面 | 拾い方 | 見るファイル | 知らせ方 |
| --- | --- | --- | --- |
| セッションの始まり | `session.start` | プロジェクトのルート（`$.session.root()`）の AGENTS.md と CLAUDE.md | トースト |
| Claude がファイルを編集した | `tool.call` の Edit・Write・MultiEdit が成功したとき | 編集したファイルが AGENTS.md なら、そのファイル（どのフォルダでも）。ルートの CLAUDE.md なら、それ | トーストと、Claude への一言（ツールの結果のあとに添える） |
| ターンの終わり | メインの `turn.complete` | ルートの AGENTS.md と CLAUDE.md。前に見たときから更新時刻が変わっていたときだけ読み直す | トースト |

ターンの終わりにも見るのは、シェルのコマンド（Python のスクリプトなど）で書き換えたときは、Edit・Write の知らせが出ないからです。

## 何を見るか

- **AGENTS.md の長さ**：行数と文字数が、どちらか一方でも目安を超えたら知らせます。
  - 目安は設定で変えられます。初期値は 100行・6,000字です（全体の指示書と同じ値）。
  - 文字数は、改行を含む文字の数です（LF の改行のファイルでは `wc -m` と同じ数）。改行コードの CRLF は1文字と数え、Windows で書いたファイルでも数が変わらないようにします。
  - 行数は、最後の行に改行がなくても1行と数えます。末尾の改行のうしろは数えません。
- **ルートの CLAUDE.md の中身**：`@AGENTS.md`（`@./AGENTS.md` も）と空行のほかに何か書いてあれば知らせます。プロジェクトの指示書は AGENTS.md の1か所に書く決まりだからです。
  - 見るのはルートの CLAUDE.md だけです。Island-survival-game の `ゲーム開発/CLAUDE.md` のように、チームのフォルダに決まりを置く作りは認めています。

## 知らせる文

- **トースト（ユーザーへ）**
  > AGENTS.md が目安を超えています（120行・7,400字／目安 100行・6,000字）。削る候補を Claude に出してもらうのがおすすめです。

  > CLAUDE.md に @AGENTS.md 以外の中身があります。AGENTS.md へ移すのがおすすめです。

  ルートでない AGENTS.md のときは、見出しを「AGENTS.md（ゲーム開発/）」のようにフォルダつきにします。
- **Claude への一言（編集したときだけ）**
  > 〔agents-guard〕AGENTS.md は 120行・7,400字で、目安（100行・6,000字）を超えています。全体の指示書の決まりに従い、消す・まとめる・別の資料へ出す候補をユーザーに示してください。了承なしに削らないでください。

  CLAUDE.md のときは「CLAUDE.md は `@AGENTS.md` の1行だけにする決まりです。中身を AGENTS.md へ移す案をユーザーに示してください」と添えます。
- Claude への一言は、ツールの結果のあとに添える文（`context`）で渡します。ユーザーの画面には出ません。

## うるさくしない決まり

- **同じ状態では二度言わない**：ファイルごとに、最後に知らせたときの行数・文字数を覚えておきます。
  - セッションの始まりでは、超えていれば必ず1回知らせます（新しい会話で、まず気づけるように）。
  - そのあとは、前に知らせたときより増えたときだけ、また知らせます。減ったときや、変わらないときは知らせません。
  - 目安以下に戻ったら、覚えた値を消します（また超えたら知らせます）。
- **Claude への一言**は、編集で増えたときだけ添えます。削っている途中で、まだ目安を超えているときには添えません（減っているので）。
- 覚えておく値は、セッションの状態（`$.state`）に持ちます。セッションをまたいでは覚えません。

## 対象外

- AGENTS.md を自分で削ったり、書き換えたりすること
- Codex が編集したときに知らせること（Codex では mod が動きません。次に Claude Code でそのプロジェクトを開いたときの、セッションの始まりの知らせで気づけます）
- 中身の良し悪し（重なり、古い決まり）を見ること。長さだけを見ます
- サブエージェントの編集でのトースト。Claude への一言は、編集したサブエージェントに渡します

## 設定（`/plugin configure agents-guard@claude-mods`）

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| `maxLines` | 100 | AGENTS.md の行数の目安 |
| `maxChars` | 6000 | AGENTS.md の文字数の目安 |
| `checkClaudeMd` | true | ルートの CLAUDE.md に中身があるかを見る |

## かかる費用と、コンテキストへの影響

- API 呼び出しはありません。ファイルを読むだけです。
- Claude への一言は、目安を超えた AGENTS.md を編集で増やしたときだけ、1回あたり百字ほど入ります。

## テスト

`claude plugin test plugins/agents-guard` で、次の場合を確かめます。

- 長さの数え方（CRLF、末尾の改行の有無、日本語）が上のとおりになること
- CLAUDE.md の中身の判定（`@AGENTS.md` だけ、空行つき、`@./AGENTS.md`、ほかの文あり）
- セッションの始まりに、目安を超えた AGENTS.md と、中身のある CLAUDE.md を知らせること。目安以下なら何も言わないこと。ファイルがなければ何も言わないこと
- Edit で AGENTS.md を増やして目安を超えたときに、トーストと Claude への一言が出ること。同じ長さの編集では二度言わないこと。減らしたときは言わないこと
- サブフォルダの AGENTS.md の編集で、フォルダつきの見出しになること。サブフォルダの CLAUDE.md は見ないこと
- 失敗した編集、AGENTS.md 以外のファイルの編集では何もしないこと
- ターンの終わりに、更新時刻が変わっていたら読み直して知らせること。変わっていなければ読まないこと
- 設定の目安を変えると、それに従うこと
