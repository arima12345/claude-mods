# goal2

Claude Code の `/goal` の改良版です。ゴールの条件を決めると、本当に達成するまで作業を続けます。

本体の `/goal` との違い:

- **判定が二段構え**: 止まるたびに軽い判定（初期設定は Haiku）が会話を読みます。「達成」と出たときだけ、確認役のサブエージェント（初期設定は Sonnet）がファイルを開いたりテストを動かしたりして実物を確かめます。確認役はファイルを書き換えません。
- **確認コマンド**: `--check "npm test"` のように指定すると、そのコマンドが通るまで終わりません。通らないまま止まろうとするのが続くと、空回りとして扱います（下の「空回りの検出」）。
- **あきらめない**: 判定役が「無理」「後回し」と言っても終わりません。ユーザーにしか決められないこと（好みの選択、パスワードなど）で止まったときだけ一時停止して知らせます。
- **自動再開**: 利用上限やエラーで止まったら、1分・5分・15分と間を空けて自動で再開します（最大6回）。ログインや支払いのエラーは自動では直せないので、一時停止して知らせます。
- **空回りの検出**: 同じ理由で3回続けて未達なら、やり方を変えるよう指示します。5回続いたら一時停止して知らせます。
- **途中の別の質問**: ゴールの途中で「今日の天気は?」のようにゴールと関係のないことを打ち込んだときは、判定役がそれを見分け、その返事で止まれます（確認コマンドが通っていなくても止まれます。判定の回数にも数えません）。ゴールは残ったままなので、作業に戻るときは「続けて」と打つか `/goal2 resume` を使います。
- **上限**: 判定は30回まで（設定で変更可）。超えたら一時停止して知らせます。
- **状態表示**: 画面下に「ゴール実行中 · 判定3/30 · 未達: テストが1件失敗」のように出ます。

## 動作環境

Claude Code 2.1.295 以降が必要です。それより古い版では mod が読み込まれず、`/goal2` が出てきません（通知の仕組みが古い版にないため）。デスクトップアプリは自動で新しい版になります。ターミナルの `claude` は `claude --version` で確かめ、古ければ `npm install -g @anthropic-ai/claude-code@latest` で更新してください。

## 使い方

| 打つもの | 動き |
| --- | --- |
| `/goal2 日記を1件追加して一覧に表示できる` | ゴールを設定して作業を始める |
| `/goal2 アプリが起動する --check "npm test"` | テストが通るまで終わらない |
| `/goal2` | 今のゴール、判定の回数、最後の未達理由を表示 |
| `/goal2 clear` | 途中でやめる |
| `/goal2 resume` | 一時停止したゴールを再開する |

条件は「〇〇が動く」「△△のファイルができている」のように、できたかどうかがはっきり分かる書き方にすると判定が正確になります。

## 設定

`/config` に次の項目が出ます。

| 項目 | 初期設定 |
| --- | --- |
| 軽い判定のモデル | haiku |
| 確認役のモデル | sonnet |
| 判定の上限回数 | 30 |

## インストール

Claude Code の入力欄で:

```
/plugin install goal2 --marketplace arima12345/claude-mods
```

マーケットプレイスを追加するか聞かれたら `y`、続けてインストール先（スコープ）を選びます。

シェルからは:

```
claude plugin install goal2 --marketplace arima12345/claude-mods
```

デスクトップアプリでは、入力欄の横の + から Plugins を開き、Add marketplace に `arima12345/claude-mods` を入れてから Add plugin を選びます。

## 注意

- 判定と確認役の分だけ、利用枠が普段より多めに減ります。
- 組織が管理している Claude Code では、止まる瞬間への割り込みが効きません（個人のプランでは問題ありません）。
