# ja-reply

Claude の報告がほとんど英語だったら、日本語で書き直させる mod です。

CLAUDE.md で「返事は日本語で」と決めていても、長い作業のあとに英語で報告してしまうことがあります。直前の文脈がコマンドの出力やコードなどの英語で埋まり、そちらに引っぱられるためです。

この mod は、Claude が返事を終えようとしたときに返事の言語を確かめます。ほとんど英語なら、止まるのを止めて「日本語で書き直してください」と伝えます。Claude は同じターンの中で、同じ内容の報告を日本語で書き直します。そのときはトーストでも知らせます。

## 判定

- コードブロック、`インラインコード`、URL、ファイルパスは数えません。英語なのが正常な部分だからです。
- 残った地の文で、日本語（ひらがな・カタカナ・漢字）が 2 割未満なら「ほとんど英語」とします。
- 短い返事（地の文が 150 文字未満）、空の返事、サブエージェントの返事は対象外です。
- 日本語の報告に英語の名前（mod 名やブランチ名など）が混ざっていても、英語とはみなしません。

## 書き直しは1回まで

書き直しを頼むのは、ユーザーの依頼1回につき1回までです。書き直しもまた英語だった場合は、トーストで知らせるだけにして止まらせます。往復が止まらなくなるのを防ぐためです。

goal2 や edit-check が「まだ作業を続けて」と止めているあいだは何もしません。作業が本当に終わるときに確かめます。

## 設定

| 項目 | 内容 | 初期値 |
| --- | --- | --- |
| `mode` | `rewrite`：日本語で書き直させる / `notify`：知らせるだけ | `rewrite` |

書き直しを頼むと、短いやり取りが1回増えて利用枠を少し使います。気になる場合は `notify` にしてください。詳しい仕様は [SPEC.md](SPEC.md) にあります。

## インストール

Claude Code の入力欄で:

```
/plugin install ja-reply --marketplace arima12345/claude-mods
```

マーケットプレイスを追加するか聞かれたら `y`、続けてインストール先（スコープ）を選びます。デスクトップアプリでは、入力欄の横の + から Plugins を開き、Add marketplace に `arima12345/claude-mods` を入れてから Add plugin を選びます。

なお、組織が管理している Claude Code では、このイベントは組織が許可した mod でしか動きません。
