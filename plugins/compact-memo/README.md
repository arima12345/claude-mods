# compact-memo

会話の圧縮で、細かい決定事項が抜け落ちるのを防ぐ mod です。

会話が長くなると、Claude Code は古い部分を要約して詰めます（圧縮）。このとき細かい決定事項が抜け落ちて、「さっき決めたことを忘れる」ことがあります。この mod は、圧縮のたびに次の2つを行います。

- **要約への指示**：要約の担当に「ユーザーと合意した決定事項、却下した案とその理由、未解決の問題は、省略せず箇条書きで残すこと」と指示します。`/compact 〇〇` で自分の指示を付けた場合は、その後ろにつなげます。
- **退避メモ**：圧縮の直前の状況をメモにまとめ、圧縮後の会話の末尾に足して Claude に渡し直します。中身は次のとおりです。
  - いまのゴール（[goal2](../goal2) のゴール。なければ直近の依頼）
  - やることリストの残り（[progress-panel](../progress-panel) を入れている場合）
  - 変更中のファイル（`git status`）
  - このセッションのコミットと、失敗したままのテスト・チェック（progress-panel を入れている場合）

手動の `/compact` でも、自動の圧縮でも動きます。サブエージェントの会話の圧縮と、`/clear` では何もしません。メモを渡し直したときはトーストで知らせます。どちらの処理も圧縮の中で行うので、API の呼び出しは増えません。

`/compact-memo` で、直近の退避メモと、これまでの圧縮の記録（手動か自動か、そのときのコンテキスト使用率）を見られます。この記録から、実際に何%で自動圧縮が始まるかもわかります。

goal2 と progress-panel は入っていなくても動きます。その場合は、会話と git だけでメモを作ります。詳しい仕様は [SPEC.md](SPEC.md) にあります。

## インストール

Claude Code の入力欄で:

```
/plugin install compact-memo --marketplace arima12345/claude-mods
```

マーケットプレイスを追加するか聞かれたら `y`、続けてインストール先（スコープ）を選びます。デスクトップアプリでは、入力欄の横の + から Plugins を開き、Add marketplace に `arima12345/claude-mods` を入れてから Add plugin を選びます。

なお、組織が管理している Claude Code では、圧縮のイベントは組織が許可した mod でしか動きません。
